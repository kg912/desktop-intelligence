The bar is pure black so the mode is obvious at a glance. Instructions and download move to the far right. All run data below is sample data.

Behaviour

The pill appears whenever the chat is in multi-agent mode, with or without a run. It replaces the model name and the context meter, and the Compact and Reload buttons are not shown in this mode. Hover or keyboard focus opens the card, and click or Enter opens the dock. The card closes on blur or Escape. If the model a worker actually used differs from the saved one, that row shows the real model with an amber "served" tag. Narrow windows drop the sub-label before the pill itself. Single chats keep today's bar.
